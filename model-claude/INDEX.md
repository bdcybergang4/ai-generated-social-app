## 🎓 I Want to Learn the Code

### 💻 Start With These Files

1. **Backend Setup**
   - Start with: `backend/server.js` (main app)
   - Then: `backend/routes/` (see endpoints)
   - Then: `backend/controllers/` (see logic)

2. **Frontend Setup**
   - Start with: `frontend/src/App.js` (main component)
   - Then: `frontend/src/pages/` (see pages)
   - Then: `frontend/src/utils/` (see helpers)

3. **Key Security Files**
   - `backend/models/User.js` (password hashing)
   - `backend/utils/tokenUtils.js` (JWT)
   - `backend/middleware/auth.js` (authentication)
   - `backend/middleware/validation.js` (input validation)
